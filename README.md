# Automotive Cybersecurity Lab

This project simulates a vehicle Controller Area Network (CAN) environment for studying automotive cybersecurity concepts, including:

- CAN bus communication
- ECU simulation
- Attack scenarios
- Intrusion detection mechanisms
- Threat modeling based on automotive architectures

## Objectives

- Understand in-vehicle network communication
- Simulate ECU behavior over CAN
- Demonstrate common automotive cyber attacks
- Build basic intrusion detection techniques

## System Architecture

The lab consists of:
- Simulated ECUs
- CAN message bus
- Attack simulation module
- Security monitoring system

## Technologies Used

- Python (simulation + analysis)
- SocketCAN / CAN-utils (optional Linux integration)
- C++ (future ECU simulation)
- Wireshark (analysis)

## Features (Planned)

- CAN traffic generator
- Replay attack simulation
- Spoofing attack simulation
- Basic IDS (rule-based detection)
- Logging and analysis tools
